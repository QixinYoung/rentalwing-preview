开店前准备

准备好这三样发给我们，开通当天就能用：

  1. 器材清单：名称、数量、日租金；贵重的写上编号（Excel、手写拍照都行）。机器平时带哪些电池、卡，也一起写上，我们帮你配成「默认附件」。
  2. 客户名单：名称、电话；哪些是同行、哪些是学生、年框客户，标一下。
  3. 员工手机号：每人一个账号，用手机号登录。第一次用短信验证码登录，进去自己设密码。

以前的老单可以用「订单管理 → ⋯ → 补录老单」一张张补进来，补的单照样能收款、对账。

装到手机上

不用下载 App，浏览器打开店里的地址就能用。加到主屏幕后像 App 一样打开，还能收派单、到期提醒。

  1. iPhone：用 Safari 打开 → 点底部「分享」→「添加到主屏幕」。要收提醒，iOS 16.4 以上、并且从主屏幕图标打开。
  2. 安卓：用浏览器打开 → 菜单 →「添加到桌面」。华为、小米自带的浏览器和微信里也能用。
  3. 进去后在「我的 → App 与通知」里打开派单通知、每日早报。

录一张单

  1. 「订单管理 → 新建订单」，客户框里打名字或电话，回车选中。
  2. 租期一行是「起租 · 共几天 · 止租」，常用的点下面的快捷项（如「明天起 3 天」）。还不知道哪天还，点「还不知道」，先占几天档期。
  3. 器材框里打名字回车。机器配好的电池、卡会自动挂在下面，单价按这个客户的价自动带出。
  4. 改数量，附件跟着按比例变；档期不够会当场提示，差的几台可以一键改成向同行借。
  5. 点「保存」，就是一张预订单。当场就要拿走的，点「保存并出库」。

出库

  1. 打开订单，点右边的「出库」，弹出出库检查单：押金收了没、贵重器材的编号指派了没、一共几件。
  2. 用扫码枪或手机逐件扫，扫到哪台就记哪台；拿错了、多拿了当场提示。没贴码的点「手点」。
  3. 出库时刻默认是现在。17:00 以后出库，从第二天开始算钱（分界时刻能在设置里改）。
  4. 出完库可以打印出库单，或者存成图片发到微信里给客户核对。

归还

  1. 打开订单点「归还登记」，一台主器材一张卡，附件在卡里。扫码或填这次还了几件。
  2. 只还了一部分也直接确认，订单会显示「收尾中 · 还剩 N 件」，剩下的下次再登。
  3. 坏了、丢了：打开「有器材损毁」，选轻微损毁 / 需送修 / 丢失报废，拍张照片，填赔偿（还不知道就选待定）。需送修的会进维修页跟踪。
  4. 出库时漏写的附件，在卡片下面「＋ 补登附件」补上。

收款与结清

  1. 订单右边点「收款」，金额默认是还欠的数，选支付方式就行。押金用「收押金 / 退押金」，也可以直接拿押金抵尾款。
  2. 货还齐、钱收齐、押金退完，订单自动变成「已结清」。押金没退完不会结清，免得忘了退。
  3. 尾款要抹零或少收，用「⋯ → 减免并结清」。
  4. 「财务管理 → 应收与对账」里，按拖得最久的排；一个客户欠几张单可以一次收齐，对账单能导出 Excel 发给客户。

客户组与定价

  1. 「客户管理 → 客户组」：系统自带散客、同行、同行价客户三个组，你可以再建学生、年框客户这样的组。
  2. 每个组一条规则：按日租金或同行价，打几折；个别器材还能在组里单独定价。
  3. 编辑客户时选他在哪个组。以后给他录单，单价自动按组里的价带出，手改也行。

贴码与扫码

  1. 买一卷空白二维码标签（或用器材上原有的条码），贴到器材上。
  2. 「器材管理」里打开某个型号的编号管理，点「连续绑码」：屏幕上提示哪一台，就扫哪一台的码，扫一个绑一个。电池、卡这类没编号的，码绑到型号上。
  3. 在任何页面扫一下，就知道这件东西在库里还是在哪张单上。
  4. 回来一堆东西时用「订单管理 → 扫码回库」，一次扫完，系统自己认出各属于哪张单。

派助理

  1. 订单里点「＋ 增加服务」，选服务种类（如摄影助理），派给某个人；服务费跟着订单一起收。
  2. 助理在手机上的「我的派单」里看到单子，上工、下工各打一次卡，超班时长自动算。
  3. 运费、打车这类花销，助理拍截图登记报销，库管确认是向客户收还是店里出。
  4. 外请的助理不用开账号：给他发一个打卡链接，他点开就能打卡。月底在「财务管理 → 人员结算」发工资。

账号与权限

  1. 管理员（老板）：全部功能，包括整本账、月度利润、同行对账、发工资。
  2. 库管：录单、出入库、收款、催款、派人；看不到利润、借调成本和工资。
  3. 助理：只看派给自己的单，打卡、登记报销，看不到金额和客户信息。
  4. 「系统设置 → 账号」里新建账号，填姓名和手机号就行；本人第一次用验证码登录后自己设密码。
